# Story: Login

Log in to the app as the seeded dev account.

## Prerequisites

- Clone bootstrapped: `bun install`
- App running: `bun run dev`

## Steps

1. Open http://localhost:6102.
   - Splash page: app logo, "Generic PWA App", and a **Log In** button at the bottom.
2. Tap **Log In**.
   - Login form: "PWA App" heading, **Handle** field, **Password** field, and a **Log In** button (disabled while the fields are empty).
3. Enter handle `ifrit` and password `omnislash`, then tap **Log In**.
   - Welcome screen: "Welcome, ifrit" and a **Log Out** button.
